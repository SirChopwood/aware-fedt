# Aware Digital
## Front End Developer Test

### Development Environment
- Project was completed in JetBrains Webstorm Community 2025.3
- Runs entirely within Node.JS, but can be exported for hosting via other usual methods.
- No AI was used in the making of this project!
- Website should work in any screen format on any browser as a Single Page Application
- Technologies Used:
  - Vue (Component Framework)
    - Router (File Based Routing)
    - Pinia (Data Stores)
    - VueUse (Misc Utilities)
    - Unhead (Meta Tag Handling)
  - Vite (Dev Hosting and Compilation)
  - SCSS/SASS (Style Sheet Utility)
- All photos, icons and fonts are those provided by Aware
  - Exception: Light & Dark mode icons, from Icones

### How to Preview

- Ensure NodeJS is installed.
- Open a terminal to the project directory.
- run `npm install` to download and prepare all the dependencies.
- (If building from source) run `npm run package` to start hosting the prebuilt package.
- run `npm run serve` to start hosting the website.
- Open your browser of choice and navigate to [Local](http://localhost:3000) or [Network](http://192.168.0.93:3000) URLS.
